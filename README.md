# Digital-Business-Card

A responsive, multi-page digital business card and professional portfolio. This project strictly uses pure HTML and CSS implementations without JavaScript.

## Features

* **Pure HTML & CSS:** Built entirely without JavaScript, strictly following project constraints.
* **CSS-Only Theme Toggle:** Implements a dark mode and light mode switch using the HTML checkbox hack and CSS variables.
* **Fully Responsive:** Adapts seamlessly to mobile devices, tablets, and large desktop screens using CSS flexbox, grid, and media queries.
* **Multi-Page Structure:** Includes separated pages for the main profile and a dedicated section for projects and expertise.
* **External Styling:** All design rules are cleanly separated into a dedicated external stylesheet.

## Project Structure

```
├── index.html        # Main profile, background, and contact information
├── projects.html     # Dedicated page for technical skills and featured projects
├── style.css         # External stylesheet containing all design and theme logic
└── images/
    └── profile.jpg   # Profile picture
```

## Local Usage

1. Clone or download the repository to your local machine.
2. Open `index.html` in any modern web browser.
3. Use the toggle button in the top right corner to switch between Dark and Light modes.
4. Navigate between the "About" and "Projects & Expertise" pages using the navigation bar.

## Deployment

This project is deployed and published using GitHub Pages.
